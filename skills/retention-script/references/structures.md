# Script structures

Pick one per video. Mixing two usually produces a middle that drifts.

| Structure | Use when | Spine |
|---|---|---|
| Problem, causes, fix | something fails and the viewer felt it | felt loss, minimum world, named causes, fix, proof, takeaway |
| Myth list | the viewer believes wrong things | myth, why it feels true, what is true, proof; 3 to 5 times |
| Race or comparison | two options, one wins under conditions | setup, rules, round by round, verdict with its conditions |
| Journey of one object | a process with stages | follow one board, order or packet from start to end; each stop is one idea |
| Before and after | a change with a measurable effect | the before, the change, the after, the number |
| Teardown | a real incident or a real system | what happened, timeline, why, what to learn |
| Build-along | how to set something up | the result shown first, steps, result, common failures |
| Question ladder | a big "why" | each answer raises the next question, 3 to 5 rungs |

## Reference layout for a 6-minute video

| Time | Block |
|---|---|
| 0:00 to 0:30 | hook and promise |
| 0:30 to 1:15 | minimum world: only what the viewer needs to follow |
| 1:15 to 4:30 | core, 2 to 4 blocks, payoff before 3:00 |
| 4:30 to 5:20 | fix or proof |
| 5:20 to 6:00 | takeaway and the next question |

Scale it. The proportions matter more than the minutes.

## Every block earns the next

- If removing a block changes nothing the viewer understands, remove it.
- Open a small question at the start of each block and close it by the end.
- Signpost where the viewer is: "that is cause one; the second one is worse".
- A reset (new visual, insert, question, place) every 45 to 90 seconds. A change in what is shown, not a random
  effect.
