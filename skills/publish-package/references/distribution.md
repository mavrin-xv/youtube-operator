# Distribution, the first 48 hours and after

## Owned places

- Embed the video in the matching blog post. Best: a post that already ranks for the same question.
- Link it from the docs page, help article or landing page that answers the same question.
- Post it once where your audience already is (newsletter, community, chat group).

## Where the question is asked

- Answer the actual thread (subreddit, Discord, Stack Exchange, GitHub discussion, product forum) with the answer in
  text first and the video as the longer version.
- One place per thread. Never drop links in threads that did not ask.

## Social

- One post with a 30 to 60 second cut or a key frame and the takeaway in text.
- A Shorts cut is optional: one self-contained idea from the video, in its own vertical layout, linked to the long
  video. Shorts viewers behave differently; judge them on their own numbers.

## Never

Bought views, view bots, sub-for-sub, mass link drops. They corrupt the data the analytics loop learns from, and
they put the channel at risk.

## Pinned comment

Pin one comment at publish: the question you want answered, or the link the description carries, with utm. At 7
days, replace it with the answer to the most common real question.
