# Publish checklist

Run `publish_lint.py` first. Then tick every line by hand.

- [ ] Title final, deciding words in the first 40 characters.
- [ ] Thumbnail passed the phone test; 2 or 3 variants loaded in Test & Compare.
- [ ] Description follows the template; the first two lines carry the answer.
- [ ] No `{{` left from the template (the linter blocks it).
- [ ] Every link clicked once and lands where the text says.
- [ ] Owned links carry utm with this video's slug.
- [ ] Chapters re-timed against the final cut; the linter passes.
- [ ] Captions uploaded or auto captions corrected (names, numbers, terms).
- [ ] End screen: one public next video or playlist, plus subscribe.
- [ ] Cards: at most two, none in the first 30 seconds, only to public videos.
- [ ] Playlist set (one series playlist, ordered as a learning path).
- [ ] Category and language set; caption language set.
- [ ] Altered or synthetic content disclosure decided, with the reason written in the video card.
- [ ] Music and footage licences noted in the video card.
- [ ] Pinned comment written.
- [ ] A human approved the publish.
